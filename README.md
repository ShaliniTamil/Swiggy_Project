# SWIGGY SQL Project

## 📌 Project Description

A SQL database project that manages and analyzes Swiggy-related data such as customers, restaurants, menus, orders, deliveries, payments, and reviews.

## 🛠️ Technologies Used

* MySQL
* SQL
* MySQL Workbench

## 📂 Database Tables

* Customers
* Restaurants
* Menu Categories
* Menu Items
* Orders
* Delivery Partners
* Delivery
* Payments
* Reviews

## 🎯 Objective

To design a relational database for managing food ordering and delivery operations and perform SQL-based data analysis.

## 📊 Key Features

* Customer and restaurant management
* Menu and food item management
* Order tracking
* Delivery partner management
* Payment tracking
* Customer reviews and ratings
* SQL queries for data analysis

## ✅ Outcome

Successfully created a structured Swiggy database with multiple related tables, sample data, and SQL queries for analysis.
